# Project Screenshots

This folder contains screenshots and images showcasing the LegalAssist Pro application.

## Screenshot Guidelines

### Main Application Screenshots
Place your main application screenshots in this folder with descriptive names:

- `homepage.png` - Main landing page
- `chat-interface.png` - Legal chat interface
- `document-upload.png` - Document upload feature
- `legal-analysis.png` - Legal document analysis results
- `case-search.png` - Case law search functionality
- `user-dashboard.png` - User dashboard and history

### Recommended Screenshot Sizes
- **Full page screenshots**: 1920x1080 (desktop view)
- **Mobile screenshots**: 375x812 (mobile view)
- **Feature highlights**: 800x600 (focused views)

### File Naming Convention
Use descriptive names with lowercase and hyphens:
- ✅ `legal-chat-interface.png`
- ✅ `document-analysis-results.png`
- ❌ `Screenshot 1.png`
- ❌ `IMG_001.jpg`

## Adding Screenshots to README

After adding your screenshots here, update the main README.md file to include them:

```markdown
## Screenshots

### Chat Interface
![Legal Chat Interface](images/screenshots/chat-interface.png)

### Document Analysis
![Document Analysis](images/screenshots/document-analysis.png)

### Case Law Search
![Case Search](images/screenshots/case-search.png)
```

## File Formats
- Prefer **PNG** for UI screenshots (better quality)
- Use **JPG** only for photos or large images where file size matters
- Optimize images to keep file sizes reasonable (<2MB per image)
