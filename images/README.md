# Images and Assets

This folder contains all visual assets for the LegalAssist Pro project.

## Structure

```
images/
├── screenshots/          # Application screenshots
├── logos/               # Project logos and branding
├── diagrams/            # Architecture and flow diagrams
└── demo/                # Demo GIFs and videos
```

## Usage

These images are used in:
- README.md documentation
- GitHub project showcase
- Development documentation
- Marketing materials

## Adding New Images

1. Place images in appropriate subfolders
2. Use descriptive filenames
3. Optimize file sizes
4. Update documentation to reference new images
